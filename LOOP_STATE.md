    #ZRO - фиксирую позицию по текущим в зоне входа. Сделка затянулась…
    #ETHFI - фиксирую позицию по текущим полностью. Решил забрать профит…

Разбор — детерминированный (`auto`, conf 0.8): **ОДИН** интент, `close_remainder` по ZROUSDT.
Инструкция по ETHFI не дала ни действия, ни строки skipped. TR-1071 провисела ещё сутки и
закрылась 13.08 в **−8.70** вместо профита.

## Причина

Правило многосимвольного менеджмента (R2) гейтится словом «Менеджмент» в заголовке — здесь его нет
(«Доброе утро, друзья»). Дальше срабатывали правила дельт R3/R4, а они устроены так:

```
const ticker = firstHashtag(text)   // ← ПЕРВЫЙ хэштег
const ops = extractOps(text)        // ← лексикон по ВСЕМУ тексту
```

То есть второй символ отбрасывался, а его инструкция («фиксирую позицию полностью») попадала в ops
ПЕРВОГО. Повезло, что оба говорили «закрыть»: скажи автор по ETHFI «держу» — закрытие ZRO осталось
бы верным, а скажи «фиксирую половину» — ZRO закрылся бы наполовину.

## Фикс

Разбор дельт стал **посимвольным**: `#TICKER` и текст до следующего `#TICKER` — сегмент этого
символа, лексикон гоняется по своему сегменту. Один символ в сообщении — прежнее поведение
(лексикон по всему тексту: действие запросто стоит ДО хэштега — «фиксирую половину по #ARB»).

Отдельный случай — действие названо ОДИН раз на несколько символов («Фиксирую позиции полностью по
#ARB и #INJ»): приписать его первому значило бы угадать, а промолчать — потерять. Такое уходит в
AI (`reason: ambiguous_symbol`) — ровно то, ради чего модель в боте и есть.

## Дыра шире: монета, названная СЛОВОМ

Заказчик сразу указал следующий слой: «а если будет 1 тикер и дальше слово типа солана, эфир,
биток — тут ИИ должен уже по-любому анализировать». Проверка на живом парсере подтвердила:

    #ZRO - фиксирую позицию полностью.
    По солане тоже фиксирую позицию.      ← execute, интент ТОЛЬКО по ZRO

Исполнять коин-слово детерминированно нельзя: в CH1 половина текста — аналитика, где «биток
закрывается выше 64k» описывает свечу, а не приказ. Поэтому такие сообщения уходят в модель
целиком (`ambiguous_symbol`). Триггер узкий: коин-слово должно стоять в ОДНОМ предложении с
action-словом и не совпадать ни с одним хэштегом сообщения — «#ARB – остаток фиксирую. Актив не
реагирует на снижение биткоина» остаётся детерминированным.

Та же потеря в свободном тексте CH2: «Закрываю солану и эфир полностью» закрывало ТОЛЬКО солану
(правило D брало первый коин строки). Строка с двумя монетами тоже уходит в модель.
