# LOOP_STATE

## Goal: PnL расходился с балансом — журнал показывал +17 при реальных +2.6

Заказчик: «кажется, криво считается pnl: я заводил суммарно около 280 usdt, сейчас показывает pnl
+17$ при этом баланс 287 — довольно сильно расходится. Перепроверь по апи и проверь логику, если
есть проблема — исправь в корне и пересчитай текущий pnl верно».

## Сверка с биржей (Bybit API, до фикса)

| источник | значение |
|---|---|
| журнал: `SUM(trades.realized_pnl)` закрытых | **+17.05** |
| журнал: `SUM(trades.fees_paid)` закрытых | 8.38 |
| биржа: `SUM(closedPnl)` по тем же сделкам | **+8.63** |
| биржа: equity | 286 при депозите ~280 |

17.05 − 8.38 = 8.67 ≈ 8.63. Вся разница — комиссии.

## Причина 1: агрегат сделки хранил БРУТТО, а вычитал комиссию никто

`executions.exec_pnl` — брутто пофилльно (так отдаёт WS-пуш; REST-догон восстанавливает брутто из
`closedPnl` обратной формулой), `exec_fee` — отдельной колонкой. Агрегат `trades.realized_pnl`
складывал только брутто, а `fees_paid` копился рядом и НЕ ВЫЧИТАЛСЯ НИГДЕ: ни в PnL-карточках, ни
в таблице закрытых сделок, ни в winRate.

**Фикс** (`state/recalc-trade.ts`, единственный писатель денег сделки):
`realized_pnl = SUM(exec_pnl) − SUM(exec_fee)`. Пофилльные строки остаются брутто — это честная
запись сырых данных биржи; брутто восстанавливается как `realized_pnl + fees_paid`. Сходимость с
биржей становится тождеством: `closedPnl = брутто − openFee − closeFee` — ровно эта формула.

Побочно закрылись два дефекта того же корня:

- **winRate** больше не считает выигрышем сделку, съеденную комиссией (+0.1 при комиссии 0.5);
- **фандинг** прилетает отдельным исполнением с комиссией и без PnL — теперь он виден в
  результате сделки, а не только в её `fees_paid`.

## Причина 2: витрина суммировала realized только по `status='closed'`

Мимо пролетали две статьи уже состоявшихся движений денег: комиссия входа по ОТКРЫТОЙ сделке
(биржа списала её сейчас) и результат ЧАСТИЧНО закрытой (статус `partially_closed` под фильтр не
подходил). В `unrealised` они тоже не попадают — он считается от средней цены и комиссий не знает.

**Фикс** (`api/positions/positions.service.ts`): `realized = SUM(realized_pnl)` по ВСЕМ сделкам.
winRate по-прежнему только по закрытым — у незакрытой сделки исхода нет.

## Пересчёт истории и сходимость (после фикса)

Пересчитаны все 20 сделок прода: `realized_pnl` 17.05 → 7.57 (закрытые 8.67), `fees_paid` 9.48.

| | |
|---|---|
| журнал: realized (все сделки) | **+7.5677** |
| журнал: unrealised (открытые) | −4.9362 |
| **итого PnL** | **+2.6315** |
| биржа: equity | 282.3721 |
| **депозит по расчёту** (equity − PnL) | **279.74** |

Заказчик заводил «около 280» — сходится. По закрытым сделкам журнал даёт 8.6684 против 8.6260 у
биржи: разница 0.0424 — ровно сделка по DOT из декабрьской истории, которой в журнале нет вовсе
(её действия были стёрты чисткой backlog'а). Всё остальное совпадает до цента.
