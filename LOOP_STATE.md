- В dry-run `realized_pnl` не считается (всегда 0) → Win Rate осмыслен только в live; для dry-run
  честный вывод «—» (исход неизвестен), а не «0%».
- `symbol_busy`/`no_open_position` в бэктесте завышены: dry-run не реконсилит филлы TP/SL в закрытие
  позиции, символ остаётся занят → `executed=62` это НИЖНЯЯ оценка реального числа входов.
- Настройки канала (`enabled`, trade_size, leverage, cross_margin) редактируются в UI и живут в
  `channel_settings`; `EXECUTION_MODE` (.env) управляет только тем, dry-run или live исполнение.
- Отдельного экрана метрик/истории в дизайне нет — метрики отданы как API + CLI, без нового
  пункта навигации (чтобы не отклоняться от «дизайн 1:1»).
